# Power BI Business Dashboard

Capstone Power BI project analyzing **The Coffee Company's** business performance, featuring data cleaning, transformation, and interactive dashboard visualizations.

---

## 🚀 Key Features

- Cleaned and transformed raw data using **Power Query**
- Removed duplicates, handled missing/null values, and adjusted data types
- Created interactive visualizations using slicers, cards, charts, and KPIs
- Designed a user-friendly layout for business insights

---

## 🛠 Tools & Skills Used

- **Power BI**, **Power Query**
- **Data Cleaning**, **Data Modeling**, **Data Visualization**
- **DAX Functions**, **KPI Design**, **Dashboard Layouts**
